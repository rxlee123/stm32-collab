## Agent skills

### Issue tracker

Issues and specs for this repo are tracked in GitHub Issues (`rxlee123/stm32-collab`) via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five default canonical triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repo (`CONTEXT.md` and `docs/adr/` at the repo root when present). See `docs/agents/domain.md`.
